# 7단계 장면 이미지 검수

파이썬은 SC 번호로 장면 파일과 승인 참조를 모으고 누락·중복·손상·화면비를 검사한다. 시각 검수에는 실제 비교판과 원본 이미지를 사용한다. 파일 검사는 정상인데 시각 판정이 없으면 해당 컷은 확인 보류로 남긴다.

## 비교판 준비

현재 승인본의 6단계 장면 목록 JSON과 5단계 에셋 목록을 사용한다. 버전별 폴더에 파일이 있으면 현황표의 실제 경로를 `--scenes`와 `--assets`로 전달한다. 장면 이미지가 기본 `이미지폴더/장면`에 없다면 `--images`로 현재 승인 이미지 폴더를 지정한다. 작품 내 경로를 사용하고, 인트로와 별도 마무리 이미지는 본편에서 제외한다. 사용자가 마무리까지 검수하라고 했으면 `--include-closing`을 사용한다.

Python 3.10 이상과 Pillow를 사용한다. Windows의 `python`이 실행되지 않은 경우 Codex에 번들된 파이썬이 있으면 해당 실행 파일을 사용한다.

```powershell
$python = Join-Path $env:USERPROFILE '.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
$script = '<77 스킬 폴더>\scripts\review_scene_images.py'
$project = '<현재 작품의 실제 절대 경로>'
& $python $script prepare --project $project
```

기본 출력은 작품의 `이미지폴더/제작자료/7단계_이미지검수` 아래에 생긴다. `검수입력.json`에서 SC별 장면 목적·구도·인물 위치와 참조 번호(R001 등)를 확인한다. `SC_*.jpg`는 장면 비교판, `REF_*.jpg`는 해당 참조 이미지의 비교판이다. 화면에서 안 보이거나 작은 얼굴·손은 원본으로 확인한다. 잘못된 파일이나 판정이 불명확한 참조를 임의 대응시키지 않는다.

## 시각 판정

승인된 상태가 조명, 날씨, 의상 손상, 소품 변화에 맞춰 달라지는 경우 그 상태를 기준으로 본다. 군중 장면의 배경 인물과 계획에 따른 화면 밖 가림도 구분한다.

- **에셋 (`assets`)** — 중요한 소품, 장소 구조, 배경과 장면에서의 상태가 지정 참조와 맞는지 확인한다.
- **캐릭터 (`character`)** — 같은 인물의 얼굴, 나이, 체형, 머리 모양, 복식과 특징이 승인 시트 및 앞뒤 컷에서 일관되는지 확인한다.
- **신체 구조 (`anatomy`)** — 보이는 손·팔·다리·얼굴의 구조와 연결을 확인한다. 겹치거나 잘려서 판별이 어려우면 확대해 원본을 보고, 그래도 불분명하면 확인 보류로 표시한다.
- **인물 구성 (`composition`)** — 주요 인물의 수, 역할, 좌우·전후 위치, 시선, 자세, 행동과 인물 간 크기 비율을 승인 장면 목록과 대조한다.

이미지를 연 뒤 각 컷의 네 항목을 `시각판정.json`에 기록한다. 상태는 `pass`(통과), `revise`(수정 필요), `uncertain`(확인 보류), `not_applicable`(검사 대상이 없는 항목)이다. 근거를 남길 때는 어느 인물이나 요소에서 무엇이 보였는지 짧게 적는다. 참조 이미지가 지정됐는데 읽을 수 없으면 그 항목은 확인 보류로 남긴다.

```json
{
  "scenes": {
    "SC001": {
      "assets": "pass",
      "character": "pass",
      "anatomy": {"status": "revise", "note": "왼쪽 인물의 오른손 손가락이 손잡이와 붙어 있음"},
      "composition": "pass"
    }
  }
}
```

## 결과 확정

```powershell
& $python $script summarize --project $project --findings '이미지폴더/제작자료/7단계_이미지검수/시각판정.json'
```

최종 `검수결과.json`에 통과·수정 필요·확인 보류 수와 SC별 근거를 기록한다. 비교판을 준비한 뒤 장면이나 참조 파일이 바뀌었으면 기존 판정을 그대로 적용하지 않는다. 파일 이름이 바뀌거나 누락·중복·손상이 남으면 해당 컷을 수정한 후 다시 확인한다.

7단계 결과의 `sceneImageReviewPath`에 검수 결과 경로를 기록하고, 문제가 있는 SC 번호와 수정할 점을 현황표에서 보여준다. 이미지 도구로 확인할 수 없는 컷은 보류로 남긴다. MP3·SRT가 아직 없으면 이미지 검수를 먼저 진행할 수 있으며, 7단계의 본편 시간 확정은 최종 음원과 자막을 확인한 뒤 진행한다.
